- `Stage.projectileFraction` は通路外・有効な結界（高さ4.5m）・配置した江戸モデルの有限の外接箱・本堂／階段を対象にする。縁台などの高さを超える攻撃は止めない。原始形状の小物すべてや三角形単位の形状まで一致させる判定ではない。
- 女王の飛剣と弾き返した剣、主人公の手甲、魔法弾・敵の矢／青い弾を同じ遮蔽経路へ統一。壁より手前に敵がいれば命中し、壁より奥なら当たらない。手甲／魔法弾は配列の登録順ではなく最初に接触する敵を選ぶ。接触位置に飛び道具・着弾エフェクトを合わせる。手甲の射程12mもフレームの飛び越しを防ぐ。
- 魔術師のレーザーは予告線・発射表示・ダメージで同じ終点を使用。射程22m、壁／結界で短くなる。魔法の爆風も遮蔽を確認する。飛剣／手甲の帰還中にはダメージがなく、持ち主へ戻す仕様を維持。
- カメラを12点サンプリングから連続判定へ変更。江戸モデルや本堂に入り込むのを防ぎ、離れると滑らかに距離を戻す。小物の高さを超える視線と屋根より上の視線を許容する。固定の障害物のカメラ用外接箱は毎フレーム作り直さない。
- 縦向き案内が戦闘を隠す画面サイズへ回転したら一時停止し、押下中入力を解除。横へ戻しても勝手に戦闘は再開せず、「再開」で戻る。
- タッチ操作の属性・ロック・奥義・一時停止・武器切替は44px以上の押下範囲を確保。属性ボタン列を少し上げて他ボタンから離した。
