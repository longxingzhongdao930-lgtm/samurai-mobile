## 奥義のシルバードラゴンを修正

対象: `src/game/combat/DragonForm.js` と `public/models/dragonkin.glb`。
追加キャラクター画面の別GLB/CreatureMotionとは別の経路です。

- 実際の走行ポーズでは頭が腰より +Z 側にあります。ゲームの前方向と同じなので、
  `00db330` で入った `facing + Math.PI` を `facing` に戻しました。
- このFBX由来のリグはローカルZが高さ。移動成分は `Pelvis_02.position` のX/Yにあり、
  Rootのpositionを除くだけでは消えませんでした。全クリップを複製し、腰のX/Yを
  待機ポーズ基準に固定。上下の沈み込み、骨の回転、翼の動きは残しています。
  当たり判定を持つ本体と見た目の水平位置がずれないための調整です。
- 全アクションに毎回fadeOutすると、過去のフェードが再スタートします。
  直前のアクションだけをフェードアウトし、それ以前のアクションは停止します。
- 変身解除時にアクションを停止し、再変身時にコンボ・スキル・クールダウンを初期化。
- 攻撃4種/スキル3種の選択、速度、命中タイミング、ダメージは維持しています。
  ユーザーの「攻撃モーション見直して、おすすめで」に対し、既存アニメーションの
  位置ずれと遷移を改善しました。新しい攻撃アニメーションの制作ではありません。
