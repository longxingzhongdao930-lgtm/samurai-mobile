# 主人公の戦闘改善・優先10件

ユーザーの「もっと出して一気におすすめ順に入れたい」に対する実装。

1. 強化居合・竜爪に短いヒットストップ、低い打撃音、抑えた揺れを追加。同時多段の追加演出は0.15秒間隔。
2. タッチ端末のカメラ揺れは45%。OSのprefers-reduced-motionがreduceなら揺れなし、画面フラッシュなし、瀕死の明滅を固定濃度にする。設定は起動時に読む。
3. 武器変更を0.7秒先行入力できる。攻撃後半（60%かcancelAtの遅い方）で切り替える。処刑、術、被弾、死亡、全身竜化、演出中は対象外。
4. 命中から0.8秒以内に攻撃後半で持ち替えると2秒の連携猶予。次の武器攻撃1回に体幹+12。攻撃開始で消費し、その攻撃の各接触に適用。空振りからの持ち替えでは強化しない。被弾・竜化・再開で消える。
5. 寸前回避で1.4秒の反撃猶予。同じ攻撃ボタンから各武器の既存反撃モーションにつなぐ。背後への瞬間移動ではない。
6. 寸前回避で防御ゲージ18回復、静けさ12獲得。1回避につき1回。全身竜化中はこの追加報酬なし。
7. コンボの命中間隔は2.4秒から、追加命中ごとに0.1秒延長、最大3.2秒。敵に回避された接触ではコンボや命中報酬を得ない。
8. 撃破時には命中間隔を最低3.4秒にして、次の敵への移動猶予を作る。HP回復は追加しない。
9. 現在の反撃・持ち替え連携・強化居合・竜爪のうち優先度の高い案内を1つ表示。全身竜化・死亡・演出中は非表示。
10. ガード残量25%未満はバーを橙色にし、防御中なら回避・ガード解除を最優先で案内。

検証: 自動テスト50件、ビルド、実ブラウザー。刀から大太刀への連携と体幹+12、寸前回避の報酬と反撃、撃破猶予、動きを減らす設定での揺れ抑制を確認。ブラウザーエラーなし。
