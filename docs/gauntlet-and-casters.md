# 手甲と城下町の戦闘更新

## 手甲

通常攻撃は地上3連撃。攻撃を0.34秒以上押して離すとアッパー。
小型の敵が浮いた直後に攻撃を押すと空中追撃へ移る。続けて攻撃で最大2連撃、2撃後は自動で叩き落とす。
空中で長押しして離すと早めに叩き落とし、回避なら後退して着地する。
追撃しない場合、敵が死亡した場合、武器変更・復活時にも高度を解除する。
大型・ボスは浮かせず、体幹ダメージを与える。剣の女王は体幹崩し・怯み中のみ打ち上げ可能。

`GauntletAir` が有限の空中状態と高度を管理し、地面の衝突処理は既存のコントローラを使う。
敵の `airControlled` は行動を一時停止し、着地後の `airRecovery` が連続打ち上げを防ぐ。
元GLBの書き換えはせず、既存のパンチ素材と `WeaponMotion` の手の軌道で合成している。

## 剣の女王・影の魔術師

両者とも足の歩行アニメーションを停止し、地面より0.4m浮遊する。
衝突・ダメージの基準位置は地上に維持し、見た目の高さのみモデルへ加算する。
女王は元モデルの6本の剣が浮遊し、攻撃の接触時刻に合わせて突き出す。
魔術師は実際の右手骨 `CC_Base_R_Hand_085` にオーラを溜め、予告線からレーザーを撃つ。
発射の少し前に照準を固定し、横への回避が可能。ダメージは発射時に一度だけ判定する。
被弾で攻撃中断した場合は溜めを消し、死亡・破棄時にエフェクトを終了する。

## 検証

`npm test` では実モデルの足の静止・右手発射位置・レーザーの命中と横回避、
手甲の上限・着地・死亡時の解除を検証する。実ブラウザでも手甲の入力から着地まで確認する。

## 黒雨の浪人

歩行を停止し、待機と短い縮地を繰り返して接近する。
攻撃は元GLBの `Take 001` を再配置し、5.5〜6.1秒付近の剣のチラ見せを予備動作にする。
モーションの32%で主人公の背後へ縮地し、58%で一度だけ命中判定、
元モーションの7.5〜8.33秒付近を使って納刀する。チラ見せの代わりに別の剣を追加しない。
通常の発光予告はこの敵だけ省き、モデルの動きを合図にする。
縮地の経路には小刻みに地形衝突を適用し、被弾・凍結・空中追撃中には縮地しない。
