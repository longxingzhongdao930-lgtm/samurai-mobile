# 黒雨の城下町：追加機能の使い方

タイトルの「続きから」は最後のチェックポイントへ戻ります。位置・体力上限・取得属性・加護・奥義ゲージ・経過時間を保存します。途中の敵HPや飛び道具まで再現する中断セーブではありません。「はじめから」を選ぶと本編の記録を新しくします。

「設定・記録の移行」はタイトルまたはポーズから開けます。音量、音楽、カメラ感度、揺れ、画質、演出、タッチの大きさ／濃さ／左右配置、ガード操作を変更できます。画質だけ次回起動から適用します。設定と撃破・探索記録はブラウザに保存します。

端末を変える場合は「記録を書き出す」でJSONを保存し、移行先で「旅の記録を読み込む」を選び、タイトルの「続きから」で再開してください。移行対象は本編のチェックポイントです。端末ごとの操作設定や図鑑の発見・撃破履歴は含みません。読み込み後は、古いプレイからの自動保存を止めて読み込んだ記録を保護します。

「稽古と強敵再戦」には、弾き・回避、女王の飛剣返し、手甲の引き寄せ、魔術師のレーザー回避があります。稽古中は体力・術・奥義が回復します。本編で撃破した6体と古竜は再戦できます。再戦では通常どおり死亡し、勝利すると選択画面へ戻ります。どちらも本編セーブを更新しません。退出はポーズからタイトルへ。

標準ゲームパッドは左スティック移動、右スティック視点、A攻撃、B回避、X魔法、Y武器変更、LBガード、RBロック、LT奥義、RT攻撃、十字キー左右で属性変更、Startで一時停止です。画面の選択は左スティック上下／十字キー上下とA、設定値は左スティック左右で操作できます。切断すると停止します。実機ごとの互換性は標準マッピング対応に依存します。

主道の暖かい提灯を進むと本筋、淡い霊火の書付を探すと攻略の記録、赤い結界の先は強敵です。書付は設定の「街の記録」から読み直せます。そこから6体のモデルとモーション付き図鑑へ移動できます。

敵の予兆は記号と文字でも表示します。「△危」はガード不可、「◇弾」は弾きを狙う合図、「↔避」は回避が必要です。画面外の予兆には破線と「！」が付きます。見づらい場合は演出を「視認性優先」にしてください。

読み込みに失敗した場合は、表示された「このデータを再読み込み」で失敗分だけを再試行します。戦闘中なら一時停止し、復旧後に「再開」で戻れます。
