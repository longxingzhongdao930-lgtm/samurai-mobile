# 黒雨モーションライブラリ

元骨格は主人公の人型骨格です。`public/animations/katana/` の21クリップには、骨名、親子関係、基準位置・回転・スケール (`sourceRest`) と30fpsのローカル骨アニメーションを保存しています。元ファイルを維持し、補正結果を別ファイルへ保存します。完全な参考動画トレースではなく再構成です。

## 再利用

- 元骨格を保った外見差し替え：骨名・親子関係・基準姿勢・スケールを変更せず、同じリグへスキニングしてください。Three.js の AnimationClip.parse でクリップを読み込めます。
- 別の人型骨格：MotionRetarget.js と MotionRigPresets.js の対応表で別クリップを生成。元骨格／モデルは変更しません。腕の軸、腰の高さ、胸の傾きを補正してください。
- 足の接地、体格差による手と柄・鞘の接触、竜など人型以外の骨格は個別の調整が必要です。全キャラに無補正で同じ見た目になる保証はありません。
- ジャンプの移動、疾走の世界座標移動、武器装着、攻撃判定、エフェクトはゲーム側で制御します。クリップ単体には含めません。

`motions.html` の確認ボットで骨格表示、キャラ切替、GLB読込、速度・位置確認、対応表と軸補正、補正済みJSON保存ができます。「元骨格・全モーションを一括保存」でマスター骨格と21クリップ、対応表をまとめて保存します。元モデルのスキニングやメッシュはこのJSONには含まれません。

検証：npm test、npm run build、scripts/check-motion-bot-browser.py、scripts/check-vergil-techniques-browser.py。ブラウザスクリプトはローカルpreviewを4181番で起動して使用します。

バージル専用の全598ボーン版を `public/animations/vergil/` に追加。詳細は [vergil-full-rig.md](vergil-full-rig.md)。確認ボットでバージルを選ぶとこの21クリップへ切り替わります。
