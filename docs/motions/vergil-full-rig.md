# バージルのゲーム用全骨格移植（2026-10-05）

## 実装

ユーザーの最新指示により通常表示は侍。`?hero=vergil` の指定時だけバージルを表示。元の侍FBXとゲーム側の移動・判定・装備リグは保持し、最終的な骨の姿勢から別の表示リグを駆動する。通常URLまたは `?hero=samurai` で侍を表示する。モデル読み込み失敗時は旧表示を保持する。

原本GLBの598ボーン、親子関係、各骨のスケール・長さを保持。22の主関節を移植し、基準姿勢の骨方向補正と手足のIKを行う。手足の接触補正の後に呼吸・細部を重ねる。納刀直立ではバージル自身の腕の長さに合わせて右手を脱力し、歩行中は腕を振る。左手は既存の鞘位置を握る。

指30関節の握り／緩み、胸と顎の呼吸、まぶたの瞬き、目線、髪・コート・襟・鞘紐の小さな揺れ、肘・膝・腿の補助骨を追加。補助骨は関節の曲がりに連動させる。その他の骨も削除せず、親の動きに追従する基準姿勢を維持する。598本がすべて独立したオリジナル演技を持つという意味ではない。布の揺れは小さな手続き動作で、衝突付きの布シミュレーションではない。

細部の振幅は `src/game/hero/VergilRig.js` の VERGIL_DETAIL を初期値とし、実行中は `app.game.vergil.config` で変更できる。変更後のクリップは export-vergil-full-rig-browser.py で再生成する。元骨格は変更しない。

## 配色

ユーザーの動画の保存済みフレーム `/tmp/vergil-walk-01.jpg` を実際に確認。DMC4SEの青灰色コート、暗い服、暗褐色ブーツ、控えめな銀髪に合わせた独自の材質。色は VergilMaterials.js の VERGIL_PALETTE、布の細かな質感は生成した小さなテクスチャ。原作画像テクスチャを復元したものではない。メッシュ形状はアップロードされたDMC5版で、動画のDMC4SEと服の形は異なる。

## 再利用

public/animations/vergil/ に30fps・21クリップを保存。各クリップは全598ボーンの回転と腰のローカル位置、全骨格の基準位置・回転・スケール・親名を持つ。確認ボットのバージル選択では専用クリップを読む。補正して別保存、一括保存が可能。Three.jsが取り込み時に一部の骨名のピリオドを除去するが、原本GLBの骨名は変更していない。

刀・鞘は既存ゲーム装備を使い、GLB内の重複武器メッシュは非表示。クリップ単体は世界座標の移動・武器装着・判定・エフェクトを含まない。別キャラへは専用対応表／体格調整が必要。
