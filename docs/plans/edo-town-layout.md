## 中心となる考え方

表通りに商店、奥に裏長屋と共同井戸。木戸と番屋で町の区切りを作り、広場で見通しを回復する。寺社への道では商店密度を下げ、さらに先は塀と門で屋敷・城郭の領域へ切り替える。建物の用途ごとに配置し、すべての道を商店と灯籠で埋めない。

一般的な江戸らしさと、今回のゲーム上の調整を区別する:

- 表店と裏の生活空間を分ける。裏長屋は農家とは異なるので、茅葺き農家を長屋の代用として市街地に連続配置しない。
- 木戸・番屋は町境の目印にする。すべての路地に豪華な城門を置かない。
- 火の見は町を見渡す目印。町の消防施設と番屋の関係を見せ、塔を密集させない。
- 地面は土の道を主体にし、排水・門前・参道に限定して石を使う。全域が均一な石畳の景観は避ける。
- 提灯・行灯は店先や入口の明かりとして集中させる。常時祭礼のような頭上の提灯列は減らす。
- 武家屋敷側は長い塀と落ち着いた門構えにする。商店の看板を混在させない。
- 江戸の水運を取り入れる川沿い区画は次の拡張候補。既存の陸路マップへ船だけを置かない。
- 参道と寺社周辺には地蔵・石灯籠等の用途に合った場所を用意する。石仏や石塔を単なるランダムな飾りとして全街路に置かない。

## 配置順

1. 表通りの店種と、裏庭の生活感を作る。
2. 広場の火の見・番屋・屋台で現在地を分かりやすくする。
3. 門前茶屋と参道の目印を配置する。
4. 塀と高麗門で最終区画の雰囲気を切り替える。
5. 川沿い・農村・室内は別区画として後から増設する。

東京駅、ボンネットバス、バスガール用小物は今回の時代設定には採用しない。花魁・職人・旅人のセットは主に特定Poser人物用の衣装で、新しい完成済みNPCとは扱わない。柴犬はモデルがあるが、ゲーム用の歩行モーションやAIは別途必要。
