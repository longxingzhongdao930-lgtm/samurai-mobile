## 映像を入手したら追う項目

各技を「予備動作→踏み込み→接触→振り抜き→残心→納刀」に分け、フレームと足の接地点、腰の向き、両手位置、刀の根元/切先、鞘口を記録する。カメラ移動は身体の移動と分離する。元の速度で比較してからゲーム向けに尺を調整する。直接見えていない奥行きは推定として区別する。

主人公には骨格・体格に合わせてIKで合わせる。接触判定は既存戦闘処理を使い、見た目だけ先行したり、刀が鞘から離れて飛んだりしないことを横/正面/背面で確認する。元映像と照合できるまでは「トレース済み」と記載しない。

## DMC4SEバージルについての設計参考

以下は既知のゲーム仕様からの整理で、上記動画を視聴した結果ではない。

- 閻魔刀：抜刀の速さと、斬った後の静止・納刀の対比。現行主人公にはまずこのリズムを合わせる。
- 次元斬：納刀姿勢から離れた位置へ斬撃。通常の刀の接触判定とは分けて扱う必要がある。
- 疾走居合：踏み込みと斬撃を一体にする。移動距離だけ増やして当たり判定を置き去りにしない。
- エアトリック：敵への接近手段。既存の縮地へ応用する場合も壁を通り抜けない。
- コンセントレイション：冷静で正確な立ち回りを評価する仕組み。既存の「静」ゲージとの重複を避ける。

DMC5のドッペルゲンガー・真魔人の仕様をDMC4SEのものとして混ぜない。今回は新たな必殺技やゲージを追加せず、震えの修正と参考資料の解析まで。
