# 主人公50案：実装対応表

対象：ユーザーが主人公のおすすめ1〜50に対して「全部」と承認。既存機能を維持する項目と追加を区別する。

操作：C／「納」／左スティック押し込み＝納刀・構え解除・竜化解除。V／「蹴」／右スティック押し込み＝蹴り。納刀後の攻撃長押しで居合を構え、離すと抜刀。構え中のガード・回避・術・持ち替えは中断可能。

|番号|案|実装・範囲|
|---|---|---|
|1|納刀を決め技に|命中後1回だけ納刀報酬。近くに敵がいれば静24、離れていれば12。次の重撃に体幹補正|
|2|手甲から居合|命中した手甲の帰還後2秒の連携。手甲中に納刀→構え→離すと帰還を待ち、刀へ持ち替えて抜刀|
|3|見切りから背後|入力ありの見切り時、敵の背後寄りへ最大2.5mの衝突掃引移動。カメラの瞬間反転なし|
|4|方向別の弾き反撃|攻撃元の左右を記録。正面は腕を伸ばし、横は胴を斬り返し方向へ補正|
|5|変身解除の接続|時間切れでは開始済みの最後の接触を最大1秒待ち、解除から中断可能な納刀姿勢へ。無敵の短い復帰猶予を維持|
|6|構えと負傷表現|静100時の低い姿勢、瀕死の呼吸音・体動、被弾による羽織の色変化。移動速度は低下させない|
|7|方向別攻撃|前入力は踏込増、横は短い側方移動と弧拡張、後ろは突進なし＋命中後後退|
|8|移動できる居合|構え中は通常速度の28%で移動。攻撃を離して抜く|
|9|適正間合い|刀・槍の射程72〜100%で命中すると体幹+3、鋭い接触音|
|10|命中と空振り|命中では短い身体の反動、空振りでは振り抜く反動。既存ヒットストップを維持|
|11|手甲の曲線帰還|横入力で帰還に曲がりを付け、見通しのある帰還経路上で1回だけ威力40%の接触判定|
|12|手甲不在時の戦闘|飛行中の攻撃で近距離蹴り。長押し空中追撃は既存機能を維持|
|13|大型相手の手甲|引き寄せ重撃が大型へ命中すると主人公側が最大3m接近。壁・敵との距離を制限|
|14|間合いを作る蹴り|既存の蹴りクリップで低威力・押し出し。連打間隔0.8秒|
|15|属性刀|命中で霊力3を消費し、火は短い燃焼、氷は減速、雷は体幹加算。未取得属性を増やさない|
|16|切替のつなぎ|以前の武器を記録し、次の攻撃へ腕のつなぎと小さい体幹補正。既存の命中後切替連携を維持|
|17|短い位置別処刑|正面／背後／大型で上体・腕を補正、周囲に敵が多ければ再生を加速。既存処刑を土台にする|
|18|武器を引き継ぐ竜化|手甲・大太刀・その他で変身初撃の実クリップを分岐|
|19|停止と振り向き|既存の減速・歩行ブレンドを維持し、停止時の上体の踏ん張りを追加|
|20|戦闘後の余韻|最後の敵の撃破後、攻撃終了を待って短い納刀。移動・攻撃等で中断|
|21|抜かずに構えを解く|構え中のガード／回避／納刀入力で解除。攻撃は勝手に出さない|
|22|距離で身かわし|正面の攻撃を射程外0.45m以内へ後退して外すと1秒の反撃受付|
|23|飛び道具切断|攻撃接触フレーム付近で通常弾を切断。レーザー・回避必須攻撃は対象外|
|24|手甲の帰還ガード|飛行中にガードすると呼び戻す。帰還直後、正面の1撃を弾く短い受付|

|29|竜化の早期解除|納刀入力で解除。残り時間の65%、最大ゲージ65%を保持。満タンを返して即再変身する循環は不可|
|30|銀竜の守り|翼ガード用の独立した消耗量。通常被ダメージを抑え、ガード不可攻撃は防げない|
|31|距離による構え|近い敵への腕の構えと、遠い敵への低い構えを小さく補正|
|32|足の接地|歩ける地面の高さを使う脚IK。±12cm以内の補正で極端な伸びを抑える。通行不可の本堂階段を登れるようにする変更は含まない|
|33|視線と上体|首を先に、胸を小さく追従。角度制限・フレーム前復元で累積ねじれを防ぐ|
|34|衣服の揺れ|軽量な羽織の裾を移動速度と停止後の遅れで揺らす。布物理シミュレーションではない|
|35|戦い方の称号|無傷／弾き／連撃／見切りに応じた結果称号。数値バフなし|
|36|主人公の試着試技|本編セーブを保護する専用稽古。7武器・攻撃・竜化・外見の確認|
|37|先行入力|既存0.32秒の攻撃等の入力保持と0.7秒の持替予約を維持。新入力も同じ期限で失効|

|41|狙われる身体反応|画面外予兆がある間、肩を小さく引く。既存警告表示を維持|
|42|手甲の指の状態|元モデルを複製した実行時ジオメトリの指先側だけを軽く曲げる。待機／射出／掴みで変化し、配布GLBは変更しない|

## 検証の範囲

`npm test` 86件成功、`npm run build` 成功。`scripts/check-hero-browser.py` は実モデルで納刀・構え中移動／解除・抜刀・蹴り・部分竜化／任意解除・帰還ガード・大型接近・外見・型・試技の保存保護・写真書出しを検証する。

既存の `check-combat-browser.py`、`check-journey-browser.py`、`check-presentation-browser.py` で本編・セーブ・操作・図鑑を確認。動作確認には直接状態設定と時間送りを利用しており、50項目すべてを人間が手操作で攻略した検証ではない。新しい外見・姿勢は既存モデルへの軽量な補助で、衣装ごとの専用スキニングや手作業の新規アニメーション一式ではない。実スマホFPS・発熱、公開デプロイ完了は別確認。
