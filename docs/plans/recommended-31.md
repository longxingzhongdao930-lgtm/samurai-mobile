再現：`npm test`、`npm run build`、previewを4173番で起動して `scripts/check-combat-browser.py`、`scripts/check-journey-browser.py`、`scripts/check-presentation-browser.py`。Python PlaywrightとChromiumが必要。`GAME_URL` と `CHROMIUM_PATH` で変更できる。

戦闘通し検証は実アセットを使うが、テレポート・直接ダメージ・時間送りを利用する。実機のタッチ感、難易度、FPS／発熱は別途確認が必要。公開配信の成功はローカルビルド／push成功から断定しない。
