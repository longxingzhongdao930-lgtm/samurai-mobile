# 主人公の静けさと竜爪

2026-10-04。主人公全体のおすすめ変更として実装。新しい操作ボタンは追加しない。

- 防御成功で「静」が12、弾き成功で34増える（上限100）。ガード崩れは対象外。
- 静100で刀の長押し攻撃を開始すると消費し、その居合だけダメージ1.6倍、体幹1.5倍。通常攻撃と他の武器は消費しない。開始後に中断されても返却しない。
- 全武器の直接攻撃命中で「竜」が10増える。範囲攻撃で一気に満タンにならないよう獲得間隔は0.18秒。
- 竜100の次の有効な直接命中で消費。追加ダメージ10・体幹24とともに、左腕へ青白い霊体の竜爪を0.8秒表示する。
- 竜爪は簡素な鱗と爪のエフェクト。シルバードラゴンのメッシュを切り出したものではない。元の手甲モデルや主人公の骨格を変更しない。
- 回避された攻撃、継続ダメージ、処刑は竜の蓄積対象外。奥義の全身竜化中も両方の蓄積・消費は停止する。
- 武器変更で蓄積を維持。死亡後の再開で両方リセット。全身竜化から戻ったときは蓄積を維持。
- HP等の下に「静」「竜」の数値と準備完了を表示。

実装: `DualSpirit.js`、`PlayerCombat.js`、`Game.js`、`HUD.js`。
検証: 武器変更、単発の居合強化、獲得間隔、回避時の保持、継続ダメージ除外、再開時のリセットを含む自動テスト45件成功。ビルド成功。
実ブラウザーでも弾き3回→長押し居合、直接命中10回→次の命中で竜爪表示を確認。JavaScriptエラーなし。
