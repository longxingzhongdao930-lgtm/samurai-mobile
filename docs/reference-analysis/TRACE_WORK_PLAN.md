# 継続作業：エフェクト→全技→全体のトレース

2026-10-05 JST、ユーザーが順序と継続を指定。エフェクトの差が終わったら、そのまま全技へ進み、全技が終わったら全体を見直す。各段階で実装だけで止めず、実ゲームの動画撮影→参照とのフレーム比較→修正→再撮影を繰り返す。

1. エフェクト：斬線の軌道、紫の雲、残像移動、発生・消失タイミング。
2. 全技：参照の特定、未実装技の導入、全身姿勢、刀・鞘・手の接触、各段の順序、足運び、打数、効果と命中時刻。
3. 全体：歩行、直立と呼吸、構え、抜刀、納刀、回避、ジャンプ、移動、技間の接続と中断、敵との位置関係、カメラ、演出の見え方。
4. 検証と記録：実操作、動画、骨格時系列、参照範囲、計測値、修正前後、残る差を保存。原本・ユーザーstash・WIPを保持する。

## 完了判定

各項目には参照動画名と区間を付ける。編集切替、別作品・別武器・変身状態、固定2倍速の録画を区別する。カメラと対象の縮尺を合わせて比較する。対応する参照がない技を「完全トレース済み」としない。見えない関節の奥行きや異なる骨格は推定であることを残す。単体テスト成功、動画の存在、ケース数、クリップ数を一致の証明にしない。

確認済みの一致と、視覚的に違う点・計測できない点を分けて記録する。参照や評価条件が足りない場合も、独立して進められる項目を継続する。
