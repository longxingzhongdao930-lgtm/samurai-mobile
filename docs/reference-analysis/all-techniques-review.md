## 修正

- quick slash／heavenly strike 2：元FBXの戻し・構え直しを外した後の上段姿勢を修正。右手を肩より高く、刀先は左手の鞘口へ下向き。前回の「刀先を上向き」は参照と逆だった。腕長は変えず、左手を胸側へ引き上げる。
- 抜刀一閃の静止0.22秒、天翔居合0.28秒。合計0.60／0.88秒。実際の一撃前後だけ残像を出す。保持後は直接納刀。手が高いこと、腕の回転が保持区間に変化しないこと、終了後に自由状態へ戻ることを確認。
- 通常連斬の首・体幹を歩行基準で起こす。斬り上げの高い位置を保持。連斬の各命中時刻へ残像を分割し、締めまで帯が残り続ける状態を減らす。
- 通常刀技でも鞘口が左手へ追従。納刀の作業位置を腰より22cm上へ変更し、携行姿勢に戻る。
- 次元斬・絶：最初0.46秒は起こした体幹と掲げた右腕。斬撃開始から低い姿勢へ。ガード／回避／終了時には専用準備ポーズを解除。
- 再利用用の単刀モーション22本をゲームの最終骨格から再保存。原本モデル・元FBX・ユーザーstashとWIPは保持。
