## 今回の実装

「主人公の支度」→「刀装」→「二刀流」。選択と保存・復元は単刀と同じ仕組み。供給された katana.glb の刀・鞘を分離・軽量化した dual-katana.glb と dual-katana-scabbard.glb をそれぞれ2本使用する。

右刀を肩付近、左刀を低く持つ待機姿勢。ガードは前で交差する2本の刀。左腰の鞘口を少しずらし、納刀は左刀の動作を先に始め、右刀を0.4秒遅らせる。完了を1.15秒に延ばし、両方が収まる前に納刀成功報酬を付けない。抜刀は左刀を先に離し、右刀は0.16秒だけ鞘内に維持して追従する。

元のKatanaSheathを左右の手に適用できるよう拡張し、各刀の反りに沿う挿入と実際の手の位置・手首方向を保持。単刀では右手・左手の支えを従来どおり使う。二刀では両手が刀を持つので支えの手は使わず、2本とも腰に固定した鞘へ納める。左手側にも装備マウントを設け、骨のワールド縮尺を打ち消す。描画確認で左刀が小さく見える問題を発見し修正した。武器を切り替えると左刀・追加鞘・納刀表示コピーを取り外す。

歩行・回避・下半身のアニメーションクリップは変更していない。攻撃の当たり判定・ダメージ・主刀の戦闘クリップは既存katanaのまま。左刀の攻撃補助動作は手続き的な独自実装であり、参考動画の戦闘コンボをトレースしたものではない。

## 中断時の右刀の遅延修正

右刀を0.16秒保持する抜刀処理が、ガード・回避・hurt状態への移行にも掛かっていた。右刀の保持をheavy攻撃の開始中に限定し、ガードの交差構えも待ち時間なしで反映するよう修正。

30fpsで60フレームの納刀を計測し、両手の柄接触を維持、最後はsheathedへ正常移行。

形状検査を納刀中の9回のサンプルへ拡張。各回にシーンの全ワールド行列を更新して、最新の刀・鞘の実形状を検査する。左刀は0.25秒以後の104〜220頂点、右刀は遅れて始まる動作の0.65秒以後の104〜220頂点で外側0。

## 納刀開始を段階化

両刀で先に手を20cm持ち上げ（0〜0.08秒）、持っている腕の届く範囲で刀を鞘口から引き離し（0.08〜0.18秒）、向きを合わせ（0.18〜0.34秒）、差し込む（0.34〜0.65秒）段階へ変更。右刀の開始を0.4秒遅らせる順序、1.15秒の完了判定は維持する。骨の両手の共通到達範囲は単刀だけに適用し、二刀は各刀を持つ腕だけの到達範囲を使う。左鞘は右鞘の基準位置より10.5cm低く・進行方向と逆へ7cmずらし、低く構えた刀と持ち上げ始めの軌道を避ける。

開始時に刀が鞘から離れている場合、鞘の軸へ投影したZが正というだけで「外側の頂点」と扱う旧検査は、干渉の証明にはならない。今回、刀身の三角形の辺から鞘へ有限距離のレイを飛ばし、交差前後1mmの点で4方向の内包判定が変わる交差を数える検査を追加。鞘口の2cm以内と刀の鍔・柄を除く。モデル内部の装飾面・キャップ等と鞘の外側の境界を区別する。

最初の検査で左刀の持ち上げ・回転途中に境界交差が見つかったため、腕の到達範囲と鞘の位置を修正して再検証した。最新版は0.05、0.10、0.15、0.20、0.25、0.30、0.35、0.40、0.45、0.50、0.55、0.60、0.65、0.70、0.75、0.80、0.85、0.90、1.0、1.1、1.3秒の21サンプル、両刀で境界交差0。サンプルはarts.tの時計を1/60秒ずつ進めて取得し、各回の全ワールド行列を更新して検査する。各刀の開始から0.4秒以後には、鞘内にある刀身頂点の4方向内包検査も外側0。
