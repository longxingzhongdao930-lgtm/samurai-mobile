# 刀を見せない技へ再選考

ユーザー指摘「何も出ていない」を受けて再撮影。前版の通常納刀光は幅22cm・0.08秒でほぼ判読できない。billboardのonBeforeRenderでQuaternionだけを変更しmatrixWorldを再計算していなかったため、表示の向きがカメラへ正しく追従しない不具合も修正。元動画には黒余白が大きいものがあり、各アトラスの発光範囲へ余白を詰めた。

最新版方針：地上12種は刀身を露出させず、納刀音と光と敵の反応で攻撃を伝える。通常は71330の小さな雷光を幅70cm・0.22秒、実命中時に敵の胸へ127578の光を幅90cm・0.28秒。強攻撃は同じ溜めと納刀に、敵側220078の紫の弧を幅1.7m。絶は127577/220078/182612の3種類を幅3.2m・0.38秒で飛ばし、納刀後127578の幅4m・0.4秒閃光。絶の2秒溜め・世界減速・姿を消す移動・帰還・納刀後のダメージは維持。地上攻撃・次元斬／絶の処理中は表示用の刀モデルを隠す。空中の既存動作は今回の再設計対象外。
