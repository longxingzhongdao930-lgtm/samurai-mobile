## 周囲と主人公の時計を分離

Appの主人公のコントローラー・骨格・武器・技・カメラは通常速度。絶が有効な間は従来の全体スロー／ヒットストップを主人公の時計に掛けない。敵の移動・AI・アニメーション、飛行中の魔法、背景の時間・雨・落ち葉へ0.12倍の周囲時計を渡す。画面UIとカメラの応答は保つ。

スローは溜めから納刀後の最後の命中まで続き、完了時に通常速度へ戻る。ガード／回避で中断、死亡・リセットでも解除。既存の他のスロー演出のタイマーを絶のために書き換えない。ポーズ中に溜め時計を進めない。
