## 修正

移動中の腰に自作3Dの開いた斬撃弧を追加。初回は白い細い輪に見えたため、217度の開いた弧にし、青い芯と約15cmの最大幅へ修正。次元斬・絶の移動区間だけに表示し、帰還・納刀・中断で解除する。形状は black-rain-waist.glb、64三角形・約7KB。既存の実刀のSlashTrailも維持。これは刀の実軌跡と同一であると測定したものではなく、参考の腰の青い弧を再構成した演出。

広域斬撃にも立体雲を追加。床寄りの扁平な体積を使い、5つの密度の塊と流れるノイズで煙を再構成。初回の紫の霧を暗く、疎な部分と濃い塊に分けた。前から順に合成する不透明度は0.95以下に制限して過積算を防ぐ。低画質は8ステップ、その他12ステップ。通常次元斬は球状の雲を維持し、広域の塊の設定を混ぜない。

空走姿勢は脚の前後の曲げを残し、元の crouch の横開きとひねりを減らす。骨の局所位置や長さを変更しない。全骨の基準姿勢と階層は保持。移動区間の足先の平均水平間隔は0.649m→0.522m、最大0.704m→0.574m。これは修正前後のゲーム内計測であり、映像から原作のメートル単位の間隔を測定した値ではない。

絶の納刀だけは専用の0.84秒へ同期。通常納刀は1.14秒を維持し、キャンセルとリセットで専用速度を解除。開始2.667秒、破裂と最終命中は3.533秒（旧3.833秒）。現行の参照短縮時計の目標3.50秒との差は0.033秒。参照の2倍速報告を考慮した時計全体を0.35倍へ短縮しているため、原作の実時間そのものに一致したわけではない。
