## 変更

専用クリップ「黒雨・次元斬絶・帰還掲刀」を作成し、元の骨の位置・長さ・階層を保持。左脚を曲げ、右脚の曲げを抑え、体幹は歩行基準の直立へ寄せた。帰還時に身体へ0.12mの浮き上がりを加え、納刀終盤に解除する。浮いた足を通常納刀の固定点として捕まえないようにし、完了・中断で専用ポーズを解除した。

絶専用の納刀では、左手の鞘口を腰の前へ置き、右手と実際に表示する刀の柄を合わせる。短く腰を横切ってから刃を上に掲げて保持し、最後に外側へ回して鞘へ入れる。通常納刀は既存の時間・挙動を維持。関節の届く距離を超える目標を制限する。基準点の一致は指の接触や全身の貫通解消の証明ではない。

自作3D black-rain-flash.glbを追加。青白い水平・垂直・斜めの細い面を組み、主人公の胸の位置で短く発光する。カメラに向く光学的な閃光として扱い、敵の最終命中の演出とは発生位置を分ける。技の間だけ通常カメラを少し上げて引く。既存の斬線・雲・移動・モバイル連打修正を保持。
