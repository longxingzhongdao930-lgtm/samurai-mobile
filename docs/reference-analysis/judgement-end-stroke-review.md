## 修正

旧計算では手の引き出し量がsin(πphase)、刀の向きがsin(2πphase)に従い、1回の空走中に手と刀の向きが戻っていた。共通のendStrokeへ変更し、各空走の12–68%で一方向へ払った後、残り32%で手の引き出し量と身体に対する刀の向きを保持する。角度・区間はゲーム用の再構成値であり、動画から正確に計測した原作値ではない。

腰の青い弧も同じ時計と角度を使い、払いの期間だけ表示。実刀のSlashTrailもこの期間だけ新しい点を生成し、停止後は既存の短い残光が消える。残像は従来の一律0.32秒から各空走区間の0.28秒（最後は0.32秒）へ合わせ、独立骨格の手・刀も同じendStrokeを使用する。次元斬・絶専用の変更であり、通常斬りの軌道は変更していない。

既存の帰還掲刀・納刀・最後の閃光、72ダメージ、納刀完了後の命中、スマホ連打修正を保持する。雲と破裂の形状は今回変更していない。
