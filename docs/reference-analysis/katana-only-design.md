# 刀一本への当てはめ設計（2026-10-05）

## 決定と実装範囲

ユーザー「武器刀だけでいい」「どう当てはめるか詳しく」。刀のみ装備可能。単刀3種の外見は維持し、他武器の保存セットは刀へ移行。元の戦績は保持。切り替え表示・手甲の型・手甲稽古表示を整理。連携の加護は無効な持ち替え追撃から弾き反撃の体幹+8へ変更。旧武器定義／モデルは履歴と互換性のため残すが選択不可。

以下は採用設計であり全実装済みではない。現時点のQは属性魔法、Rは既存奥義、Vは蹴り、Eは武器切り替え無効。未実装入力の説明を実際の操作ガイドに出さない。

## 姿勢・関節・武器の接続

普段：背筋を伸ばし、両腕を下ろす。左手は鞘の中央寄りを握り、歩行に合わせて前後に振る。鞘は斜め下／後方へ、胴体と前腕の外側を通す。
次元斬：普段の鞘を連続軌道で左腰前へ運び、左手を鞘口へ。膝を曲げ、腰を下げ、胸と骨盤を半身へ。右手を柄へ寄せ、短い抜き納め。終了時に両腕を下げて通常へ戻す。
疾走居合：次元斬の小さな動きとは別に、抜き付け・進路移動・停止・回収を設ける。手と柄は常時接続。姿勢と移動の命中時刻を合わせる。
全技：先に骨盤・胸・支持脚を定め、次に肩・肘、最後に手首と刀を合わせる。元動画に見えない奥行きは体格に合わせた再構成とし、完全一致と記載しない。

## 効果・敵との関係

次元斬はロック敵位置を発動時に確定する。対象不在なら射程内の前方地点。壁の向こうや範囲外は弾く。予告、斬線、実際のダメージの時刻を揃える。球の光だけで攻撃判定を成立させない。
幻影剣は手甲や手裏剣モデルを投げる代用ではなく専用の魔力剣。まず直線射出を実装し、周回・敵包囲・雨状派生は段階追加。剣の女王の実剣投射とは別。
次元斬・絶は派手さだけでなく画面の敵・道路を読める演出を優先する。低画質では剣・線の本数を減らし、ダメージ回数を増やさない。
既存属性や竜化を置き換える際はセーブ・HUD・チュートリアルを同時に移行する。刀のみ制限の今回コミットではまだ変更しない。

## 実装の順番と検証

1. 刀のみ選択・旧装備の移行（今回実装）。
2. 次元斬の独立入力と中腰・短い抜き納め・敵位置の斬撃。
3. 基本連斬の全段と入力待ちによる分岐。
4. 斬り上げ、空中連斬、降下と着地。
5. 疾走居合の派生、短距離Trick風移動。
6. 幻影剣と次元斬・絶、HUD・ゲージ・旧属性／竜化からの移行。

各段階で録画して参照と比較し、手と柄の接触、前腕と鞘の距離、足の接地、攻撃後の直立復帰、入力キャンセル、壁際・対象不在、低画質を検証する。テスト成功だけで映像一致と扱わない。
