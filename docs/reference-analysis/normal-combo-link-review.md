# 通常攻撃5段の接続修正

参照はユーザー添付 `20261004-0746-52.8952967.mp4` の通常状態 Yamato Combo A（約0.9–1.9秒）。申告の2倍速を戻した並列比較を使用。原作データの抽出ではなく、侍と現行5段入力への再構成。原作と全段の打数・足運びが一致したという認定ではない。

## 変更

- 1・2段の横払い／斬り返しを優先し、5段とも切り終わりを入力受付中に保持。前段の終点から次段を開始する。
- 次の入力前に腕補正が復元されるため、最終表示後の手・刀のワールド姿勢を保存して接続する。復元後の腕を接続元にすると刀が跳ねる問題を撮影で確認し修正した。
- 体幹のひねりと沈み込みを増やす。脚は固定の歩行1フレームから、段ごとに左右の支持脚を変える歩行サンプルへ変更。途中停止は元の立ち姿勢へ回収する。
- k1–k5 の再利用モーションを実際のゲーム骨格から再保存。各31トラック、元の30骨の sourceRest（親子・長さ・スケール）は変更しない。技名、命中数・威力、派生、他27モーション、元モデル、ユーザーのstash/WIPは保持。

## 検証

177テスト・最終ビルド成功。実入力の全5段接続と連打、終了後free、全骨格値有限、ページエラー0を確認。固定カメラ2秒・30fps・60コマを撮影し、最終の並列比較MP4を作成（/tmp/combo-five/reference-comparison.mp4）。撮影後に保存済みの再現スクリプトを撮影なしで再実行し、同じ接続制約を確認した。テスト成功を見た目の一致の証明にはしない。

段切り替えの30fps隣接コマで、手の移動は順に1.52cm・1.09cm・0.49cm・2.56cm、刀の向きの変化は約0.0048度・0度・0度・3.07度。修正途中で見つかった1→2の約19cm／65.6度の跳ねを解消した。これは原作の各関節との一致度ではなく、段間の接続の計測。計測 normal-combo-metrics.json、画像 normal-combo-gameplay.jpg。

再利用ライブラリ32本の保存／読み込みと4骨格（Tpose・侍・女王・魔術師）の対応も確認。Tpose31対応・不足0、他3体23対応・不足8（既存の末端／補助骨の差）。主要骨は対応。
