# 自作3Dエフェクトの制作・比較記録

最新の継続結果は judgement-end-pass4-review.md。自作GLBは6種類（腰の開いた弧 black-rain-waist.glb を追加）。以下の初版の時刻は履歴であり、最新の絶の破裂は3.533秒。

エフェクトの立体形状は src/game/fx/KatanaEffectGeometry.js で制作。元モデルの形状抽出・改名ではない。`node scripts/build-katana-effects.mjs` で編集用GLBを再生成する。ゲームは同じ生成関数から作る形状を直接使用するため、GLB取得に依存しない。

- black-rain-slash.glb: 三日月状の斬線、64三角形。次元斬の払いで右手位置から発生。通常の刀の残像は、実際の刀先・根元から生成する既存の自作SlashTrailを使用する。
- black-rain-rift.glb: 立体的に交差する直線斬撃、128三角形。次元斬・幻影剣の命中に導入。
- black-rain-end.glb: 広域に交差する斬線、384三角形。次元斬・絶の初撃に導入。
- black-rain-burst.glb: 最終命中の放射状破裂、16三角形。絶の3撃目に導入。
- 空間雲: テクスチャ不要の自作シェーダーで球体内部を8／12段階でレイマーチ。GLBに専用シェーダーは含めない。

参照は0748-41の通常次元斬、0750-07の次元斬・絶（0.40–5.80秒の同一場面。冒頭の別場面を除く）。通常／変身・3SE比較・編集切替を混ぜない。ユーザー申告の2倍速は固定区間を2倍の時間へ戻して比較する。初版の曲線状の裂け目を撮影し、参照の白い直線交差との違いを確認して直線へ変更した。次元斬・絶も輪状から長い斜線の交差へ変更。紫の空間雲を追加。再撮影は /tmp/katana-original-fx-sequence と /tmp/katana-original-fx-burst、初版は /tmp/katana-original-fx、途中版は /tmp/katana-original-fx-revised に保持。

通常次元斬は技開始0.30秒で右手の払い、0.38秒で遠方の裂け目が発生。絶は0.46/0.58/0.70秒の命中と同期。払いの寿命0.12秒、その他の形状の寿命0.24秒、最大不透明度は払い0.30／交差斬線・破裂0.42／絶の広域斬線0.18、深度書込みなし。これらは現行ゲームの時間設定であり、参照の全時間・全ピクセルと完全一致した値という主張ではない。再撮影JSONのeffectsに可視形状の不透明度・縮尺・位置を記録する。

既存Force Edgeは幻影剣の剣モデルとして使用を継続し、出典を保持する。以前のjudgement-cut-end.glbも保存するが、演出の実行時には読み込まない。他者の剣モデルを自作と呼ばない。

## 未完了の比較点

完全トレースは未認定。斬線の本数・角度・動く順序、空間雲の濃度と渦、刀元から出る青い払いの軌道・明るさ、絶の残像移動・画面全体の紫色変化・最終破裂の大きさと発生時間はまだ一致しない。カメラ・舞台・骨格も違う。暗い城下町での視認性を保ったゲーム用の初期実装であり、テストの成功を完全一致の証明にしない。

## 2026-10-05：段階表示と残像の再比較

紫の雲と斬線を別の時間曲線に分離。現行寿命は払い0.18秒、遠方の裂け目0.42秒、広域斬線0.40秒、破裂0.30秒。裂け目は発生直後に雲、0.12秒後から斬線を出し、雲は0.32秒で消す。球体内部の雲は自作ノイズを積算し、自作の分岐雷形状 black-rain-lightning.glb を追加した。前節の0.12／0.24秒は初版の値。

全身残像はSkeletonUtilsで骨格を独立複製し、移動方向を向かせる。高い構えの静止コピーが横滑りしていたため、複製側にslashHit／crouchSlashを再生するよう修正。主人公の骨格・座標は残像処理から変更しない。この斬撃は既存クリップによる中間実装であり、参照の跳躍・回転・刀軌道を完全トレースした動作ではない。

再撮影先：/tmp/katana-fx-trace-pass2/animated-reshoot。JSONには雲・雷の不透明度、残像の世界座標・進行率・クリップ名も記録し、WebGLシェーダーのコンソールエラーを検査する。次元斬・絶の現行約1秒の技時間と参照区間の時間差、納刀前後の順序、残像の全身姿勢は引き続き未一致。

### 再比較後の追加修正

0750-07の参照では広域斬撃の後に身体が戻り、納刀を経て最後の破裂が出る。ゲームの破裂は0.70秒で納刀前だったため、納刀完了後に延期し、途中中断・死亡・新しい技開始時には予約を破棄するよう修正した。命中3回の時刻は現段階では従来の0.46／0.58／0.70秒を維持しており、最終ダメージと遅延した破裂の同期は未修正。

比較一覧画像が長い参照の冒頭3秒だけを表示していた問題も修正し、9コマを参照の全区間に等間隔配置する。再生速度の見出しは「申告された2倍速の補正」とし、編集映像自体のスロー再生を原速と断定しない。ゲームの終端静止画延長は編集として明示する。

最終命中も納刀後の破裂と同期するよう変更。前の中間版では3回目のダメージが先に入っていたが、最終版では納刀完了時に対象の生存・可視性・9m範囲を再確認して1回だけ命中させる。中断時には最終ダメージも発生させない。

最終再撮影：/tmp/katana-fx-trace-pass2/synced-burst-reshoot/end.mp4（30fps、84コマ）。破裂の初出は2.167秒、最終表示は2.433秒で、全表示フレームのmodeはsheathed。比較動画は /tmp/katana-fx-trace-pass2/synced-review/compare-end.mp4。実キー操作ではE24、F72、連続E72ダメージ、中断時の最終命中取消、空中からの復帰を確認。154テストとビルド成功、ブラウザ／シェーダーエラーなし。参照の約10.8秒（申告2倍速補正）に対し現行演出は約2.4秒で終わるため、時間一致は未達。

## 2026-10-05：連続移動を先行させる段階構成

0750-07の同一場面をもとに JudgementEndSequence.js を追加。参照の録画時刻0.6／1.0／1.4／1.8／2.2秒を5回の移動の代表点とし、広域斬撃2.8秒、戻り4.0秒、納刀への移行4.2秒、破裂5.4秒を別段階として管理する。代表点の身体姿勢はまだ参照から再構成できていない。

現行ゲームは申告2倍速を補正した参照時間を0.35倍へ短縮する明示的な適応。残像0.14／0.42／0.70／0.98／1.26秒、広域斬撃1.68秒、2撃目1.96秒、構えへ戻る2.52秒、納刀開始2.66秒。既存納刀が1.14秒あるため最終破裂は約3.8秒になる。参照時計はendSequence(1)で保持するが、現行ゲームの時間が完全一致するという意味ではない。

残像は直線往復から横方向の弧と0.35／0.65mの浮き上がりを持つ軌道へ変更。奥行き・距離・高さは異なるカメラからの推定。独立した複製骨格に既存slashHit／crouchSlashを再生し、全5回が低画質の2体プールでも脱落せず広域斬撃前に消えることをテストした。広域斬線の表示時間は0.7秒へ延長し、戻る前に消す。主人公本体はまだ同じ地点に残り、原作の実体移動・跳躍・回転は再構成できていない。これが次の大きい未一致点。

次元斬絶の再利用クリップを4.5秒で再出力し、納刀から直立への復帰も記録する。他の既存クリップを呼吸時刻の差だけで再保存しない。

今回の実測（30fps、138コマ）：残像0.167–1.567秒、広域斬線1.700–2.367秒、納刀2.667–3.800秒、最終破裂3.833–4.133秒。残像の発生は5回を録画JSONから確認した。各段階の先後関係、破裂中のsheathed状態、全骨格の有限値、シェーダーエラーなしを確認。157テスト、ビルド、実キー操作でE24／F72／連続E72ダメージ、最終命中の中断取消を確認。録画：/tmp/katana-sequence3-capture/end.mp4、参照比較：/tmp/katana-sequence3-review/compare-end.mp4。

## 本体移動の再構成と再撮影

JudgementEndTraversal.jsで、残像に加えて本体も移動するよう変更。各段の終点を次の段の始点とし、向きは最短の角度で補間する。浮き上がりは身体全体にかけ、元のボーンの親子関係・長さを保持する。腰の水平移動を直接ねじ込む方法は使わない。移動は通常のコントローラーwarpとstage.moveSafelyを通す。中断すると、その場所に留まって浮き上がり・専用ポーズを解除し、無理に原点へ戻さない。

再撮影は固定カメラ、30fps、138コマ。最大移動2.427m、最大浮き上がり0.646m。最後は元の(0,0,124)へ帰還し、高さの追加オフセットは0。録画JSONにroot座標とtraversalの高さ・有効状態を追加した。参照と比べると本体の反転・回転、膝・肘の角度、刀の軌道、時間配分はまだ一致しない。曲線・高さ・距離はカメラの違いを含む推定であり、完全トレースではない。

骨格クリップのJSONへmovement.samplesを追加し、骨のローカル単位とは別のメートル単位で位置・向き・高さを保存する。実ゲームの出力は136サンプル、4.5秒。MotionBotで別の人型にも移動を再生でき、シーク・調整保存・32クリップのライブラリ保存でデータを保持する。表示範囲を移動の最大範囲に合わせて調整。影の魔術師の手マッピングに存在しない056／082を使っていた問題は、実モデルの057／085へ修正。4体の主要ボーンは対応し、末端補助ボーンは対象モデルに無いものを残したまま報告する。4体の再生が完全に同じ身体姿勢になるとの主張はしない。
