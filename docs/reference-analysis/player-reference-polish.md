# 納刀・操作・空中技の更新（2026-10-04）

単刀・二刀の納刀を添付録画の時刻へ合わせ、握りと刀身の収まりを保つIKで再構成した。
納刀中は待機クリップを保持し、旧居合クリップの深いしゃがみを使わない。居合の溜めだけ従来の構えを使用する。
刀が収まった後は手を下げる。手を離した後の刀は鞘に追従するので、腕に引かれて抜けない。
既存の歩行・回避クリップと、元の素材・ユーザーstash・別ブランチWIPは保持している。

## 参照と時間

単刀は `20261004-0559-13.3378157.mp4` の3.64–6.16秒を基準に2.52秒の納刀。
血払いは0559-59録画を参考に0.8秒で別動作として追加する。
二刀は `20261004-0617-29.4656965.mp4` の血払い0–2.1秒、左刀2.1–3.3秒、右刀4.8–6.6秒を基準にする。
同名0617-29アップロードは重複資料として扱い、別モーションを追加しない。
二刀では左を納めてから右を肩上で待たせ、その後に右を納める。
`SheathReference.js` に各段階の実時間を置き、ゲームの終了判定と表示で共有する。
動画の編集・カメラ移動・単眼の奥行きは3D骨格の完全な計測ではない。
体格と刀の長さの差はIKで補正している。不可視の奥行きと全ボーンの完全一致は検証できておらず、完全一致と称しない。
MMD VMDや元ゲームのアニメーションデータを新しく公開素材へコピーしていない。

納刀後の脱力では意図して柄から手を離す。接触検証はその時点まで行い、その後は刀と鞘の一致を検証する。

## 操作と武器切り替え

- Shift左右: 回避。Space: ジャンプ。Alt左右: 歩き。画面の説明・回避ヒント・キー表示を変更。
- タッチにもジャンプボタンを追加。
- 切り替えは刀 → 二刀 → 大太刀 → 槍 → 薙刀 → 鎖鎌 → 手甲 → 手裏剣 → 刀。
- 二刀は既存のkatana保存ID＋dual刀装で表現し、古い装備セットを移行せず使用できる。
- 選んでいた単刀をsingleSwordとして記憶し、二刀から刀へ戻ると復元する。
- 二刀の読み込みは完了後に一括で適用。死亡・被弾・変身・ジャンプ中など適用できない状態では変更しない。
- Fキーの武器変更と性能表示の競合を解消。ゲーム中の性能表示はF8。

## 空中技

Space後に攻撃すると武器別の空中技を出す。
刀は空中斬り、二刀は左右の交差斬り、大太刀は着地斬り、槍は空中突き、薙刀は空中薙ぎ。
鎖鎌は空中刈り、手甲は空中射出、手裏剣は空中投げ。
大太刀は着地時に20ダメージの周囲攻撃と衝撃波を一度だけ出し、被弾・死亡・持ち替えでは予約を破棄する。
攻撃クリップは腕と上体だけを使い、ジャンプの脚と上下動を維持する。地上の踏み込みワープを空中へ適用しない。
槍・薙刀・大太刀は専用の腕姿勢を使用し、命中時刻へ合わせる。手の目標位置も跳躍の高さに追従する。
Vergilの0748-59録画終盤のAerial Rave Aを再確認して参考にしたが、各武器の技は独自制作であり動画の完全トレースではない。
