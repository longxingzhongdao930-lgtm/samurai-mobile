# 納刀・操作・空中技の更新（2026-10-04）

単刀・二刀の納刀を添付録画の時刻へ合わせ、握りと刀身の収まりを保つIKで再構成した。
納刀中は待機クリップを保持し、旧居合クリップの深いしゃがみを使わない。居合の溜めだけ従来の構えを使用する。
刀が収まった後は手を下げる。手を離した後の刀は鞘に追従するので、腕に引かれて抜けない。
既存の歩行・回避クリップと、元の素材・ユーザーstash・別ブランチWIPは保持している。

## 操作と武器切り替え

- Shift左右: 回避。Space: ジャンプ。Alt左右: 歩き。画面の説明・回避ヒント・キー表示を変更。
- タッチにもジャンプボタンを追加。
- 切り替えは刀 → 二刀 → 大太刀 → 槍 → 薙刀 → 鎖鎌 → 手甲 → 手裏剣 → 刀。
- 二刀は既存のkatana保存ID＋dual刀装で表現し、古い装備セットを移行せず使用できる。
- 選んでいた単刀をsingleSwordとして記憶し、二刀から刀へ戻ると復元する。
- 二刀の読み込みは完了後に一括で適用。死亡・被弾・変身・ジャンプ中など適用できない状態では変更しない。
- Fキーの武器変更と性能表示の競合を解消。ゲーム中の性能表示はF8。

## 空中技

Space後に攻撃すると武器別の空中技を出す。
刀は空中斬り、二刀は左右の交差斬り、大太刀は着地斬り、槍は空中突き、薙刀は空中薙ぎ。
鎖鎌は空中刈り、手甲は空中射出、手裏剣は空中投げ。
大太刀は着地時に20ダメージの周囲攻撃と衝撃波を一度だけ出し、被弾・死亡・持ち替えでは予約を破棄する。
攻撃クリップは腕と上体だけを使い、ジャンプの脚と上下動を維持する。地上の踏み込みワープを空中へ適用しない。
槍・薙刀・大太刀は専用の腕姿勢を使用し、命中時刻へ合わせる。手の目標位置も跳躍の高さに追従する。
Vergilの0748-59録画終盤のAerial Rave Aを再確認して参考にしたが、各武器の技は独自制作であり動画の完全トレースではない。

## 専用の体幹所作と両手の脱力（2026-10-04）

単刀の納刀に `SheathBody` を追加。持ち上げ・引き・合わせ・挿入・脱力の時計に合わせ、腰に近いSpine、胸、肩、頭を少量ずつ連動させる。Hips・脚のトラックと元の攻撃は変更しない。
納刀中は敵へ顔を向ける待機補正や足の地形補正を混ぜない。普通の中断では体幹補正を短時間で解除し、被弾・死亡では直ちに解除。
右手の脱力に40ms遅れて左手も鞘口から離す。刀身は鞘へ残す。肘の曲げ方向を身体の外側・下・少し前へ固定し、腰を横切る目標でも身体内側へ反転しにくくする。
既存の二ボーンIKを利用した。Fullikの新規依存追加は行わず、追加ライブラリの必要性と専用所作の問題を分離している。
これは観察した区間へ合わせた自作の補助所作で、参照動画の全ボーンを完全一致させたものではない。二刀の専用体幹所作と空中技の追加作り分けは次の対象。
正面・横の画像と体幹・脚・手の計測は `scripts/check-sheath-body-browser.py`、出力は `/tmp/sheath-body/`。

追加検証結果: 122テスト・ビルド成功。単刀の6姿勢・6中断・30fps・6時点の刀身内包が成功。二刀の握り・内包・遷移も成功し最大柄距離2.87e-14m、ブラウザエラー0。
待機姿勢への切替が落ち着いた状態から160フレームを計測し、専用体幹所作によるHipsと左右Footの位置変化は0m。末尾の体幹補正は全成分0で、左右の手が肩より30cm以上下がることを確認。待機姿勢への初期クロスフェード自体は脚が約1cm動くため、体幹所作の検査から分離した。ガード等への切替は別の単刀ブラウザ検証で確認。

## 納刀完了後の腕交差の修正（2026-10-04）

ユーザーの1215-26、1217-27、1217-44の録画を確認。公開版で納刀後の両腕が腹の前に残るとの報告。
完了状態を挿入状態から分離し、毎フレーム柄・鞘口へ手を寄せ直す処理を停止。刀は鞘空間にキャッシュした位置に保持し、手首は各肩より外側かつ下へ置く。持ち刀の待機姿勢も納刀状態では停止。
肘の外側方向をLeft/Rightという名前で決めていた符号がこの骨格の実位置と逆だったため、実際の肩の位置と主人公の向きから判定するよう変更した。
前の検査は手の高さだけを見ており、肘の内向きと左右の手首の間隔を見落としていた。check-sheath-body-browser.pyへ納刀完了後の長時間待機を追加し、手首・肘が肩幅より内側へ集まらないこと、両手が肩より40cm以上下がることを検証する。
録画に含まれる他の技の完全一致まで修正済みという意味ではない。公開版の配信コミットはHTTP制限のため確定していない。

修正後の検証: 122テスト・ビルド成功。納刀開始から8.7秒後も肩幅0.343mに対し肘幅0.546m・手首幅0.415mを保ち、両手は肩より40cm以上下がる。脚・Hipsの専用所作による位置変化0m。単刀の鞘内包・30fps・中断と二刀の内包・遷移が成功、ブラウザエラー0。正面の完了姿勢を画像でも確認。公開版の同症状との比較はユーザー提供録画を使用。
