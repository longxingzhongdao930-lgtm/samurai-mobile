## 反りと抜刀時の柄の接触修正

新しい形状検証で、0.25〜0.45秒に刀身の横抜けが見つかった。刀の反りを無視した直線挿入が原因だった。
SheathCurveで刀の中心線の反りを求め、形状を変形せず、挿入中の剛体回転と位置を補正。手の実際の届く距離に合わせて抜け量を解く。
実際の鞘モデルに対する4方向のレイ検査を追加。0.25、0.35、0.45、0.55、0.65、0.85秒で鞘の口から2cm以上入った刀身の全頂点を確認し、外側の頂点は全時点0（検査頂点数364、364、401、552、1511、1511）。これは6時点の頂点検査であり、全連続時間の面同士の衝突検証とは区別する。

旧装備の取り付け位置を持ち越していたため、通常の刀を正規化モデルの柄の基準点（local Z=-0.1）に合わせた。抜刀表示の補間中も実際の右手を基準に位置と手首の向きを保持。
抜刀後の20フレーム（60Hz）で柄の目標距離最大2.95e-14m、手首の方向差最大2.94e-5rad。許容値5mm・5mrad以内で成功。
