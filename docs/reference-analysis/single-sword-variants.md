# 単刀3種類の切り替え — 引き継ぎ

2026-10-04。作業ブランチ feat/katana-variants-and-dual。main 4ccf6da と以前のWIP d9118bf、元の手元変更のstashは維持。今回の機能は作業ブランチへ保存し、push・公開はしていない。

「主人公の支度」→「単刀」で神話の刀・鬼殺し・黒柄の刀を選択できる。刀と元モデルの対応する鞘を一緒に変更し、選択をhero保存データに保持。旧保存データは神話の刀へ戻る。戦闘上の武器ID・威力はkatanaのまま。

ダウンロードが逆順に終わっても最後の選択だけを適用する。失敗時は既存の刀・鞘を維持し、表示も元の選択に戻す。途中の納刀表示コピーは交換時に破棄し、新しい刀に追従する。刀の実形状を斬撃軌跡にも渡す。

追加モデルはスキン・モーションクリップなし。既存の修正済み単刀動作を適用。prepare-extra-katanas.pyで刀と鞘を分離し、柄・鍔・刀身の基準位置を合わせ、テクスチャを軽量化した。鬼殺しは鍔の前側を納刀基準にして飾りが鞘内へ入らないようにした。鞘幅は鬼殺し1.2倍、黒柄1.08倍に調整。クレジットと加工説明はpublic/model-credits.htmlに追加。
