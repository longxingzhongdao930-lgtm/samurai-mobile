# バージル参考の居合改修結果（2026-10-04）

ユーザー許可：超人的な移動・斬撃も可。ただし関節と身体のつながりを保つ。通常の判断はおすすめで進め、作業結果を報告する。費用はかけない。

## 今回変えたこと

- `VergilIai.js`：Crouchの低い脚とIdleの体幹を採取し、前傾・半身の専用保持ポーズへ再構成。元のクリップは変更しない。保持中の足の揺れを抑える。
- 重攻撃の初動をこの構えへつなぎ、終盤は待機姿勢へ戻す専用クリップを作る。斬撃中盤の下半身には既存CrouchSlashが残る。
- `VergilIaiMotion.js`：右腕と刀の軌道に専用キーを追加。肩に追従する座標で解き、肩から手の到達距離を腕長の94%以内へ制限する。既存IKの外側・下の肘曲げ面を使う。
- 居合中の左手を鞘口へ残し、終盤で離す。以前の左腕が上方へ上がる既存モーションとの競合を修正。
- 構えの鞘先を少し上へ向ける。納刀の回収は肩より上へ伸び切る目標を、体の外側・前側へ持ち出す目標へ調整。
- 居合の短い抜刀閃光、青白い刀の軌跡、命中位相の短い残光。軌跡の縁だけを描くための帯幅を追加し、保持中・終盤では強い光を出さない。通常攻撃では元の色と帯幅に戻す。
- 移動、回避、ガードの原本クリップと、二刀流を削除した状態は維持。追加ライブラリ・外部モーション素材は未導入。

## 1438-31ユーザー録画との比較

13.233秒の録画を確認。3〜6秒は0.25秒刻みの主人公の拡大画像も確認した。通常攻撃から刀を高く掲げる回収、納刀、待機・歩行、ポーズ画面が見える。この区間を「居合の溜めの実演」とは扱わない。

鞘を携える動きは出ているが、バージルの構え・踏み込み・回収との速度差は残る。今回の居合用経路変更が通常コンボにも全て適用されたとは記載しない。納刀側は外側への回収目標だけを今回調整した。
