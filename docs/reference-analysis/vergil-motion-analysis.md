## 動作をつなぐ原則

歩行では鞘を持つ左手の振りは小さく、空いている右腕が脚と交互に動く。鞘は体側から下へ垂れ、身体の中心を横切らない。上体は脚の動きに比べて静かだが、完全に固定されているわけではない。

戦闘は「鞘の保持位置を構えへ移す→右手を柄へ→抜き付けと踏み込み→斬り終わり→刀を回収→刀と鞘口を合わせる→挿入→保持姿勢へ戻す」という段階で考える。刀だけを腕から独立して動かしたり、納刀の終了フレームをそのまま歩行へ固定したりしない。全ての技がこの全段階を映しているわけではない。

斬撃は腕の振りと体幹・足の向きの変化を伴い、回収では足を落ち着かせる。右腕の逆向き回転だけで次の斬撃方向へ合わせると、体格差によって肩のねじれと胴体貫通が出る。刀の向きを決める前に支持脚、骨盤、胸の向きを定め、最後に手と柄の接触を補正する。

## 人体と貫通を確認する順序

1. 左手で持つ鞘を胴体の外へ置く。腰へ戻すときも保持手が届く連続した軌道にする。
2. 右手は柄を握り、肘が逆に曲がらない曲げ面を保持。肩・肘・手首を別々に一瞬で反転させない。
3. 抜刀は手と鞘口の間隔を広げる動きにする。刀が長くて腕だけで届かなければ左手の鞘移動と体の向きを伴わせる。
4. 斬り返しは刀を胴体の外へ回収してから次の斬撃へ。肩の回転だけで身体の中を最短距離で通さない。
5. 納刀は刀と鞘口を揃え、曲がった刀身に合わせて連続した挿入にする。身体をねじって刀の先だけ合わせない。
6. 着地と歩行復帰では脚・体幹・腕の姿勢を再評価。元の納刀・斬り終わりの腕姿勢が残らないことを録画で確認する。
