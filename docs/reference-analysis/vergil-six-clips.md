## 実装に採用する順序の提案

1. 単刀の手と柄、左手と鞘口の接触・連続した出入りを優先。納刀で刀が飛んだり震えたりしないことを確認してから攻撃を増やす。
2. 通常攻撃はCombo A/B/Cから刀の軌跡・回収姿勢を参考にする。各実演は通常／変身、4SE／3SEを区別する。
3. 居合はRapid Slashの予備姿勢、速い通過、停止後の回収を参考にする。移動距離・ダメージ・無敵時間は自作ゲームの調整であり、映像のトレースと混同しない。
4. Upper Slashは重攻撃の参考候補。空中技や変身の追加は下半身・歩行・回避を維持する現在の作業から切り離す。
5. Judgement Cutの鞘際の小さな動作と遅れて出る攻撃は将来の遠距離居合の参考。
